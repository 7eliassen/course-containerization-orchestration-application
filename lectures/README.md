# Лекции

Лекционные материалы доступны на диске дисциплины, а не хранятся в репозитории. Актуальную ссылку получите на платформе или у преподавателя; ниже приведён маршрут тем.

| Тема | Где используется |
|---|---|
| Linux для DevOps | Подготовка окружения и работа в терминале |
| Docker: основы, образы, Dockerfile | [ЛР №1](../labs/01-docker.md), [ЛР №2](../labs/02-docker-image.md) |
| Docker: данные и сети | [ЛР №3](../labs/03-persistence.md) |
| Compose, реестры и секреты | [ЛР №4](../labs/04-compose.md) |
| Kubernetes: основы и Pod | [ЛР №5](../labs/05-kubernetes.md) |
| Kubernetes: kubectl и организация | [ЛР №5](../labs/05-kubernetes.md), [ЛР №6](../labs/06-k8s-cicd.md) |
| CI/CD | [ЛР №6](../labs/06-k8s-cicd.md) |
| Наблюдаемость | Диагностика, проверки здоровья и разбор результатов работ |

Эти темы и лабораторные входят в подготовку к [экзаменационному тесту](../assessment/exam.md). Задания выполняются по порядку из [индекса лабораторных](../labs/README.md).
