# Соглашения

## Markdown

- Язык документов — русский, код и команды — в блоках кода с указанием языка.
- Имена файлов и каталогов — строчные латинские буквы через дефис.
- В каждом каталоге верхнего уровня есть `README.md` — индекс раздела.

## Лабораторные

- Каталог работы: `labs/labN-<краткое-имя>/README.md`.
- Файл отчёта: `ЛРN_Фамилия_ИСУ.pdf`.
- Сообщения коммитов: `labN: краткое описание` (например, `lab4: add redis service`).

## Что не хранится в репозитории

Лекционные материалы, пароли, токены, ответы преподавателя на задания.
