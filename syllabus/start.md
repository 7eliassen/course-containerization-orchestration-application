# Быстрый старт

Сначала подготовьте окружение и выполните ЛР №1. Форк и проект понадобятся начиная с ЛР №2, поэтому для первой работы не нужно заранее настраивать GitHub Actions.

## Подготовка

- **Платформа:** зарегистрируйтесь и запишитесь на [курс](https://sdaesh.fpin-projects.ru/subjects/889ec78f-2e1f-44b3-ab2d-bb7779e52f13); код записи получите у преподавателя.
- **Окружение:** подготовьте Docker, терминал и доступ в интернет по требованиям [ЛР №1](../labs/01-docker.md).
- **Материалы:** получите доступ к учебному чату и дискам через платформу или преподавателя.
- **Правила:** ознакомьтесь с [оцениванием](../assessment/README.md) и [порядком сдачи](submission.md).

## Первая работа

Выполните [ЛР №1](../labs/01-docker.md), заполните персональные параметры и подготовьте PDF с нужными артефактами. Загрузите отчёт в свою папку на учебном диске и запишитесь на защиту.

## Начиная со второй работы

Создайте публичный форк репозитория курса кнопкой `Fork` и клонируйте его на свой компьютер. Не создавайте Pull Request с решениями в репозиторий преподавателя.

Ветка для ЛР №2 называется `lab-2`. Приложение разместите в `solutions/assist-py/`, а для следующих работ создавайте `lab-3`, `lab-4`, `lab-5`, `lab-6` от результата предыдущей работы; инструкция подготовки приложения находится в [ЛР №2](../labs/02-docker-image.md).

Указывайте в отчёте ссылку именно на нужную ветку. Команды приложения выполняйте в `solutions/assist-py/`, а команды управления всем форком и его workflow выполняйте в корне форка.

## Если что-то не получается

Сначала откройте [частые вопросы](../materials/faq.md). Для вопроса в общий чат подготовьте номер работы, этап, каталог выполнения команды, точный текст ошибки и уже выполненные проверки; пароли и токены не публикуйте.
