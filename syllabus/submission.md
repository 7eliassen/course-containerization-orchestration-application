# Сдача и защита лабораторных

Для каждой работы нужен PDF-отчёт и защита на занятии. Начиная с ЛР №2 также требуется результат в публичном форке репозитория курса; для ЛР №1 репозиторий не нужен.

## Подготовьте результат

- **Задание:** выполните этапы работы и проверьте её критерии.
- **Репозиторий:** для ЛР №2–6 разместите проект в `solutions/assist-py/`, используйте ветку `lab-N` и обновите README приложения.
- **Отчёт:** создайте `ЛРN_Фамилия_ИО_ИСУ.pdf`, например `ЛР2_Иванов_ИА_408145.pdf`; состав разделов и скриншотов указан в задании.
- **Ссылки:** для ЛР №2–6 добавьте в PDF ссылку на нужную ветку, для ЛР №6 также ссылку на успешный запуск CI.

Загрузите PDF в свою папку ФИО на диске отчётов, внутри неё в каталог «Лабораторная N». Актуальную ссылку на диск получите на платформе или у преподавателя; начиная с ЛР №2 копию PDF также храните в `solutions/` своего форка.

Для ЛР №1 загружается только PDF на учебный диск. Создавать форк ради копии первого отчёта не требуется.

## Запишитесь на защиту

Откройте [платформу курса](https://sdaesh.fpin-projects.ru/subjects/889ec78f-2e1f-44b3-ab2d-bb7779e52f13) и выберите доступное место. Порядок работы с платформой описан в [инструкции для студента](https://github.com/rendex85/sdaesh-guides/blob/main/student/student-guide.md).

На защите покажите результат, объясните ключевые решения и ответьте на вопросы преподавателя. Без PDF, а для ЛР №2–6 также без репозитория, защита не проводится; за один день можно защитить не больше трёх работ.

## Дедлайн и штраф

Срок определяется датой защиты, а не загрузки отчёта. Если защита прошла после дедлайна на платформе, из балла за эту работу один раз вычитаются 2 балла, даже если PDF и репозиторий были подготовлены вовремя.

Штраф не повторяется за каждую неделю опоздания. Минимумы обязательных работ и общая шкала приведены в [оценивании](../assessment/README.md).

## Чек-лист перед защитой

- [ ] PDF открывается, имя файла соответствует образцу, ФИО и ИСУ указаны.
- [ ] Есть все разделы, персональные параметры и артефакты из задания.
- [ ] Для ЛР №2–6 преподавателю доступна нужная ветка форка.
- [ ] README приложения позволяет воспроизвести результат.
- [ ] В опубликованных файлах и скриншотах нет реальных паролей, токенов и ключей.
- [ ] Вы записаны на защиту и знаете дедлайн.
