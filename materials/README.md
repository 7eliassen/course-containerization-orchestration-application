- **Работы:** [задания](../labs/README.md), [порядок сдачи](../syllabus/submission.md).
- **Оформление:** [образец README приложения](../solutions/_template/README.md).
- **Помощь:** [частые вопросы](faq.md).

Требования к скриншотам, конфигурациям и PDF находятся в задании каждой лабораторной. Общие условия общения и защиты собраны в [программе курса](../syllabus/course.md).
