# Assistant

Персональный ассистент на FastAPI. Репозиторий ведётся в рамках лабораторных по Docker и Kubernetes.

Автор: Иванов Иван, ИСУ 408145

## Как запустить

```bash
docker build -t ivanov-assistant:v1 .
docker run -d --name ivanov-assistant -p 8045:8045 ivanov-assistant:v1
```

## Переменные окружения

| Переменная | Для чего | Пример |
| --- | --- | --- |
| `APP_OWNER` | ваша фамилия, показывается на главной | `ivanov` |
| `PORT` | порт приложения | `8045` |

## Как проверить

```bash
curl http://localhost:8045/health
```
