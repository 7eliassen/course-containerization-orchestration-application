# Исходный код и отчеты по лабораторным работам

В данной директории каждый обучающийся размещает свои решения лабораторных работ и отчеты в своём публичном форке этого репозитория. Преподаватель по истории коммитов видит, что и когда вы выложили.

Допускается создание дополнительных директорий в процессе решения заданий, а также настройка дополнительного проектного окружения.

## Отчёты

Отчёт по каждой работе — файл PDF с именем `ЛРN_Фамилия_ИСУ.pdf`. Копию отчёта кладите в `solutions/`, основной отчёт загружается в вашу папку на диске (см. [силлабус](../syllabus/course.md#как-сдать-лабораторную-работу)). Для ЛР №1 репозиторий не нужен, сдаётся только PDF-отчёт.

## Шаблоны

- [`_template/README.md`](_template/README.md) — образец README для вашей работы.
- [`_template/.gitignore`](_template/.gitignore) — пример `.gitignore`.

## Что не кладём

Пароли, токены, ключи и файлы окружения с реальными значениями (`.env`).
