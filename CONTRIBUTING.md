# Как вносить изменения

1. Создайте отдельную ветку.
2. Изменяйте одну тему/лабораторную за Pull Request.
3. Проверяйте относительные ссылки.
4. Убедитесь, что Mermaid и таблицы корректно отображаются на GitHub.

Студентам: свои решения не нужно присылать в Pull Request в репозиторий преподавателя: размещайте их в `solutions/` своего форка.
