## Общие требования

- **Отчёт:** `ЛРN_Фамилия_ИО_ИСУ.pdf`, например `ЛР1_Иванов_ИА_408145.pdf`.
- **Репозиторий:** результаты всех шести работ размещаются только в своём форке, не в Pull Request преподавателю.
- **Оформление:** LaTeX обязателен; используйте [комплект и инструкцию](../materials/report-format.md), коммитьте PDF и полный исходный проект.
- **README:** начиная с ЛР №2 дополняйте инструкцию воспроизведения приложения; предыдущие разделы сохраняйте.
- **Безопасность:** реальные секреты не должны попадать в Git, отчёты и скриншоты; публикуйте безопасные примеры.
- **Срок:** опоздание считается по дате защиты и даёт разовый штраф −2 балла.

Первая настройка описана в [быстром старте](../syllabus/start.md), шкала в [оценивании](../assessment/README.md), типичные вопросы в [помощи](../materials/faq.md).
