# Общая рубрика

| Уровень | Описание |
|---|---|
| 4 — отлично | корректно, обоснованно, качественно оформлено |
| 3 — хорошо | есть небольшие недочеты |
| 2 — удовлетворительно | решение частично корректно |
| 1 — недостаточно | существенные ошибки |
| 0 — нет результата | работа отсутствует или не соответствует заданию |
