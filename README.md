Осень 2026. Преподаватель: Аминов Натиг Сабит оглы. На курсе последовательно развиваем одно приложение: от контейнера Docker до Kubernetes и CI/CD.

## Маршрут курса

| Работа | Тема | Перед началом | Минимум / максимум |
|---|---|---|---|
| [ЛР №1](labs/01-docker.md) | Команды Docker и диагностика | Подготовьте Docker и терминал | 2,5 / 5 |
| [ЛР №2](labs/02-docker-image.md) | Dockerfile, образы и healthcheck | ЛР №1; создайте публичный форк | 5 / 10 |
| [ЛР №3](labs/03-persistence.md) | Данные и сети | Продолжайте проект ЛР №2 | 5 / 10 |
| [ЛР №4](labs/04-compose.md) | Docker Compose | Продолжайте проект ЛР №3 | 7,5 / 15 |
| [ЛР №5](labs/05-kubernetes.md) | Kubernetes | Стек из ЛР №4 | 7,5 / 15 |
| [ЛР №6](labs/06-k8s-cicd.md) | Два узла и CI/CD | Результат ЛР №5, напарник | 7,5 / 15 |

Для ЛР №1 нужен только PDF-отчёт. Начиная с ЛР №2 проект ведётся в `solutions/assist-py/` вашего форка, с веткой `lab-N` для каждой работы.

## Дедлайны и защита

Дедлайны и запись находятся на [платформе курса](https://sdaesh.fpin-projects.ru/subjects/889ec78f-2e1f-44b3-ab2d-bb7779e52f13). Дату опоздания определяет защита, а не загрузка отчёта: после дедлайна применяется разовый штраф −2 балла за работу.

Подробные правила, контакты и ресурсы собраны в [программе курса](syllabus/course.md). Инструкции по сдаче и расчёту баллов находятся на отдельных страницах по ссылкам выше.
